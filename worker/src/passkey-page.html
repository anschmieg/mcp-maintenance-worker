One-time tailnet setup

  1. Sign in to the Tailscale Machines page as a tailnet administrator. Copy your target host’s Tailscale IPv4 address.
  2. Enter the address below. In Access controls, merge the snippet into the matching sections of your existing policy and save. Review existing grants and ACLs that also match the new tag. Broad rules still apply.
  3. Open Trust credentials. Select Credential, then OAuth. Select Write for Auth Keys only and select tag:openbot-probe. Select Generate credential.
  4. Copy the client ID and secret to the fields below before closing Tailscale’s credential dialog.
