One-time tailnet setup

  1. In Access controls, add this tag under tagOwners. Keep the rest of your policy and check that broad rules do not grant the new tag unintended access.
  2. Open Trust credentials. Select Credential → OAuth. Select Write for Auth Keys and select tag:openbot-probe. For the device picker, select Read for Devices Core. Select Generate credential.
  3. Paste the client ID and secret below, then select Connect with OAuth.
